## 프로젝트 개요
- 목표: 데이터를 **취합하고 집계**하는 과정 학습
- 지난 프로젝트는 일별 누진 확진자 수가 이미 준비된 잘 가공된 시계열 데이터라 가공 과정을 크게 줄일 수 있었음
- 실제 현장 데이터는 대부분 잘 정리되어 있지 않고, 설문조사처럼 사람이 수작업으로 작성한 데이터는 취합·집계가 필요
- 흐름: 설문조사 진행 → 응답 취합 → 데이터 집계 → 그래프 도출

### 문제 정의
- 상황: 글로벌 소프트웨어 엔지니어가 꿈인 신후. 어느 나라를 선택하고 어느 시점에 이동할지, 어떤 기술을 배워야 할지 고민
- 질문
  - 개발자가 많은 나라와 현재 유행하는 기술 파악
  - 연령대별로 엔지니어가 사용하는 프로그래밍 언어 종류 확인
- 데이터: 전 세계 소프트웨어 엔지니어가 참여한 커뮤니티(스택 오버플로) 활용

### 그룹화
```python
revised_data.groupby(["Age"])   # DataFrameGroupBy 객체 반환
```

```python
size_by_age = revised_data.groupby(["Age"]).size()
```

```python
size_by_country = revised_data.groupby(["Country"]).size()
```

- `groupby()`는 집계를 위해 데이터를 그룹화하고, `size()`는 각 그룹의 크기를 반환

- `DataFrameGroupBy` 객체에서 `.`을 찍고 Tab을 누르면 사용 가능한 메서드 목록을 볼 수 있다

## 데이터 시각화
### 연령대별 응답자 수
```python
size_by_age.plot.line(rot=45)   # 선 그래프
size_by_age.plot.bar()          # 수직 막대
size_by_age.plot.barh()         # 수평 막대
```

- 기본 그래프는 그룹 이름이 문자 우선순위로 정렬되어, 연령 순서와 어긋남
- `reindex()`로 색인 순서를 지정해 그래프 하단에서 상단 순으로 나열

```python
reindxed_size_by_age = size_by_age.reindex(index=[
    'Prefer not to say',
    '65 years or older',
    '55-64 years old',
    '45-54 years old',
    '35-44 years old',
    '25-34 years old',
    '18-24 years old',
    'Under 18 years old'
])
reindxed_size_by_age.plot.barh()
```

### 국가별 응답자 수
```python
size_by_country.plot.pie()
```

- 기본 설정의 문제: 원이 너무 작고, 나라가 너무 많아 이름이 겹치고, 조각이 너무 잘게 나뉨

```python
size_by_country.plot.pie(figsize=(10, 10))              # 크기 조정
size_by_country.nlargest(20).plot.pie(figsize=(10, 10)) # 상위 20개만
```

- `figsize`: `(width, height)` 튜플, 단위는 인치
- `nlargest(20)`: 상위 N개 추출
- 상위 20개 순서: 미국 13543 > 인도 6639 > 독일 5395 > 영국 4190 > 캐나다 2490 > 프랑스 2328 … 오스트리아 833 > 이스라엘 795 > 이란 723 > 파키스탄 711

### 많이 사용되는 프로그래밍 언어
```python
languages = revised_data["LanguageHaveWorkedWith"]
languages   # 'JavaScript;TypeScript' 처럼 세미콜론으로 구분된 하나의 객체
```

```python
languages = languages.str.split(";")   # 문자열을 리스트로
languages

exploded_languages = languages.explode()   # 리스트 항목을 행으로
exploded_languages

size_by_languages = exploded_languages.groupby(exploded_languages).size()
size_by_languages
```

```python
size_by_languages.nlargest(10).plot.pie(figsize=(10, 10), autopct='%1.0f%%')
```

- `str.split(";")`: 한 셀에 담긴 여러 언어를 리스트로 분리
- `explode()`: 리스트 항목을 각각의 행으로 펼침(응답 1건 → 언어 수만큼 행)
- `autopct='%1.0f%%'`: 파이 조각에 백분율 표기. 파이썬 문자열 포매팅 방식
- `autopct`는 판다스가 아니라 맷플롯립의 인수이므로 판다스 문서에는 없다

### 연령대별 언어 비교
```python
languages_for_25_34 = revised_data[revised_data.Age == '25-34 years old'] \
    ["LanguageHaveWorkedWith"].str.split(";").explode()

languages_for_25_34.groupby(languages_for_25_34).size().nlargest(10) \
    .plot.pie(figsize=(10, 10), autopct='%1.0f%%')
```

- 25~34세 언어 응답은 137,808건으로, 전체(370,114건)의 약 37%를 차지
- 결론: HTML/CSS, JavaScript, TypeScript, SQL, Python까지 익히면 소프트웨어 엔지니어 취업에 도움이 될 것으로 판단

## 집계 과정 정리
| 단계 | 이 프로젝트에서 한 일 |
|---|---|
| 취합 | CSV 한 줄 = 응답 1건 |
| 분리 | `str.split(';')` → `explode()`로 한 행을 여러 행으로 |
| 집계 | `groupby().size()`로 기준별 건수 계산 |
| 정렬·선택 | `nlargest()`로 상위 N개 |
| 표현 | `plot.bar`/`barh`/`pie`, `reindex`로 순서 정리 |
