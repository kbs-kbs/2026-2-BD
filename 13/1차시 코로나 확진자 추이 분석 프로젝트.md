### 문제 정의
- 상황: 대한민국에서 하와이로 이사 온 안나. 오미크론으로 한국 감염자가 많이 늘었다고 들었고, 하와이는 공공장소에서 마스크를 쓰지 않을 정도로 상황이 좋아 보임. 방학에 친구를 초대하려는데 하와이 코로나 상황이 더 나쁘면 초대하지 못할 것 같음
- 질문: "현재 하와이의 코로나 상황이 대한민국보다 더 나은 것이 맞나요?"
- 기대 결과: 대한민국과 하와이의 감염 추이를 한눈에 비교하는 그래프
- 데이터 수집 방향
  - 대한민국 인구 약 5,160만 명, 하와이 주 약 145만 명
  - 인구가 다르므로 확진자 수 단순 비교는 바람직하지 않음
  - **일자별 총인구 대비 확진자 수 비율**의 변화 추이를 보는 것이 의미 있음

## 데이터 수집
### 적절한 데이터란
| 요소 | 질문 |
|---|---|
| 포괄성 | 필요한 데이터를 포함하는가 |
| 최신성 | 최신 데이터를 포함하는가 |

| 신뢰성 | 왜곡이 없고 신뢰할 수 있는가 |
| 사용성 | 사용하기 편한가 |

- 필요한 데이터: 각 지역의 총인구, 최신 정보를 포함한 일자별 확진자 수
- 수집 경로: 구글에서 '코로나' 검색 → 지도 아래 OWID(Our World in Data) 링크 → 실시간 그래프의 출처 확인 → COVID-19 dataset 다운로드 링크 → OWID 깃허브 프로젝트의 CSV/XLSX/JSON 중 CSV 선택

### 데이터 포맷 비교
| 포맷 | 특징 | 장점 | 단점 |
|---|---|---|---|
| CSV | 값을 콤마로 구분 | 가장 효율적인 텍스트 저장, 분석용으로 가장 많이 사용, 엑셀로 변환 쉬움 | 형식이 단순해 타입 정보 없음 |
| XLSX | 엑셀의 XML 기반 파일, 압축 저장 | 일반 사용자에게 적합, 엑셀·넘버스·구글 문서로 열람 | 텍스트 에디터로 열 수 없고 코드에서 바로 쓰기 제약 |
| JSON | JavaScript 객체 표현 방식 | 네트워크 전송의 사실상 표준, 값 표현이 유연 | CSV·XLSX보다 파일 크기가 큼 |

- `info()` 결과 읽는 법
  - 객체 데이터 타입 클래스: pandas.core.frame.DataFrame
  - 데이터 색인 범위: 200080건, 0~200079
  - 열 정보: 열 번호 0~66(67개), 이름, Non-null Count(값이 있는 항목 수), Dtype
  - 형식 요약: 64비트 실수 62개, 객체 5개

- 모든 데이터는 RAM에 올라가야 연산할 수 있으므로, 파일 크기보다 큰 여유 메모리가 필요

### 열 추리기
| 열 | 의미 |
|---|---|
| iso_code | 국제 표준 국가 코드(USA, KOR) |
| location | 국가 이름 |
| date | 일자 |
| total_cases | 전체 확진자 수 |
| population | 인구 |

```python
selected_columns = ['iso_code', 'location', 'date', 'total_cases', 'population']
revised_df = raw_df[selected_columns]
revised_df.head()
```

### 유일값 추출
```python
locations = revised_df['location']
locations          # 색인 + 국가 형태의 1차원 데이터(시리즈)
locations.unique() # ndarray로 유일값 반환
```

- 시리즈: 판다스의 1차원 데이터 타입, 파이썬 리스트보다 풍부한 기능
- `unique()`: 중복 없이 유일한 값
- ndarray: 넘파이의 배열 타입. 데이터프레임의 각 행도 결국 같은 색인을 가진 시리즈(ndarray)를 행 이름으로 나열한 것

### 국가별 데이터프레임 만들기
```python
kor_df = revised_df[revised_df.location == 'South Korea']
kor_df.head()      # 첫날 확진자 수 1.0

kor_date_index_df = kor_df.set_index('date')
kor_date_index_df.head()

usa_df = revised_df[revised_df.location == 'United States']
usa_date_index_df = usa_df.set_index('date')
usa_date_index_df.head()
```

- 대괄호 안에 조건식을 넣어 필터링, `set_index('date')`로 색인을 날짜로 변경

## 데이터 시각화
### 그래프 예시로 문법 익히기
```python
df = pd.DataFrame({
    'pig': [20, 18, 489, 675, 1776],
    'horse': [4, 25, 281, 600, 1900]
}, index=[1990, 1997, 2003, 2009, 2014])

Lines = df.plot.line()
```

- 딕셔너리의 키(pig, horse)가 범례, 값 리스트가 데이터, `index`가 x축
- 이 프로젝트에서는 키를 KOR·USA로 바꿔 사용

### 시각화용 데이터프레임
```python
kor_total_cases = kor_date_index_df['total_cases']
usa_total_cases = usa_date_index_df['total_cases']

final_df = pd.DataFrame({
    'KOR': kor_total_cases,
    'USA': usa_total_cases
}, index=kor_date_index_df.index)

final_df.plot.line()
```

### x축 범위 자르기와 라벨 회전
```python
final_df['2022-01-01':].plot.line()        # 2022년만
final_df['2022-01-01':].plot.line(rot=45)  # x축 라벨 45도
```

- `rot`은 명명 인수(named argument)로, `plot()`에서 쓸 수 있는 인수를 `line()`에서도 그대로 사용
- 판다스 공식 문서에서 'rotation'을 찾으면 `rot: int, default None` 설명 확인 가능

### 인구 비율 보정
```python
kor_population = kor_date_index_df['population']['2020-01-22']
usa_population = usa_date_index_df['population']['2020-01-22']
# 미국 인구 332915074.0 / 대한민국 인구 51305184.0

rate = round((usa_population / kor_population), 2)   # 6.49

final_revised_df = pd.DataFrame({
    'KOR': kor_total_cases * rate,   # 인구 비율 반영
    'USA': usa_total_cases
}, index=kor_date_index_df.index)

final_revised_df[:].plot.line()
final_revised_df['2022-01-01':].plot.line(rot=45)
```

- 단순 확진자 수 비교는 인구 차이로 의미가 왜곡되므로, 인구가 적은 쪽에 비율을 곱해 같은 조건으로 맞춤
- 2022년 2월 초부터 급격히 상승한 구간은 오미크론 변이 출현 시점과 맞물림

## 마무리
- 인구 대비 확진자 비율은 **대한민국 > 미국**으로 나타남
- 다만 안나가 있는 곳은 하와이 주(인구 약 140만 명, 미국 인구의 약 0.42%)이므로, 미국 전체 데이터로 결론을 확정하는 것은 정확하지 않음
- 하와이 주 데이터를 확보해 같은 방식의 선 그래프로 비교해야 문제에 답할 수 있음
