# 빅데이터개론 (2026-2)

빅데이터개론 교안(중간·기말 통합교안)을 주차·차시별로 정리한 노트입니다. 1주차 두 차시는 직접 정리한 개인 노트이고, 2주차부터 14주차까지는 교안 내용을 개념·구조·비교표 중심으로 정리했습니다.

## 범위

| 구분 | 주차 | 차시 |
|---|---|---|
| 중간 | 1 ~ 7주차 | 14차시 |
| 기말 | 9 ~ 14주차 | 12차시 |

- 8주차는 중간고사 기간으로 교안이 없습니다.
- 중간 범위는 수집·저장·처리·분석·표현 기술의 개별 도구를, 기말 범위는 플랫폼·가상화·클라우드와 파이썬 실습 프로젝트를 다룹니다.
