## 그래프 기반 빅데이터 응용
- 절차적인 빅데이터 처리·분석에서는 응용이 그래프 기반으로 구성됨
- 그래프 기반 절차적 처리는 방향 비순환 그래프(DAG)로 표현하고, 이를 이용해 다양한 데이터 소스의 대용량 데이터를 효과적으로 처리
- 작업 플로우는 DAG 기반 처리의 대표 예로, 어떤 목표를 위해 수행하는 작업의 흐름을 순차·병렬로 나타낸 것
- 여러 데이터 처리를 특정 순서로 자동화·협업화해 사용자가 새로운 결과를 얻도록 도움
- DAG에서 정점은 단계별 작업(Task), 에지는 작업 사이의 관계·의존성(Dependency)

도구 예
- 우지(Oozie): 아파치의 워크플로우 스케줄러로, 하둡에서 워크플로우를 처리하기 위한 확장성·신뢰성 있는 플랫폼 제공
- 맵리듀스를 적용한 과학 워크플로우 구성 프레임워크
- 케플러(Kepler): 맵리듀스를 활용하는 wordcount 액터로 단어 계수 워크플로우 구성

## 워크플로우 스케줄링
| 구분 | 내용 | 장점 | 단점 |
|---|---|---|---|
| 정적 스케줄링 | 실행 전에 스케줄링을 먼저 함 | 간단하고 계산이 복잡하지 않음 | 동적 환경의 성능 변화에 대응하기 어려움 |
| 동적 스케줄링 | 실행 중 실시간으로 스케줄링 | 상황 변화를 반영 | 계산 복잡도가 높음 |

## 워크플로우 관리 시스템의 5가지 분류 체계
| 분류 | 내용 | 세부 항목 |
|---|---|---|
| 워크플로우 설계 | 구조 확립과 상세 결정 | 워크플로우 구조, 모델·상세, 구성 시스템, QoS 제약 |
| 정보 검색 | 데이터·정보 형태에 따른 검색 | 고정 정보, 기왕 정보, 동적 정보 |
| 워크플로우 스케줄링 | 각 작업을 특정 자원에 할당 | 스케줄링 구조, 의사 결정, 계획 기법, 스케줄링 전략, 성능 추정 |
| 결함 감내성 관리 | 오류·실패 대응 | 작업 수준, 워크플로우 수준 |
| 중간 데이터 이동 관리 | 중간 데이터의 이동 관리 | 사용자 직접, 자동 |

## 그래프 기반 처리 기술
### 데이터 관리
- 워크플로우는 작업을 순차·병렬로 수행하고 각 작업이 서로 의존적
- 효과적 처리를 위해 메타데이터, 데이터 기원, 입력·중간·출력 데이터 관리가 중요

### 데이터 전송 최적화
- 대량 데이터를 다루므로 데이터 전송이 성능에 큰 영향
- 데이터 이동 경로 최적화: 경로를 단순화해 맵-리듀스를 파이프라인으로 묶으면 중간 데이터 통합·분할과 셔플·정렬 없이 바로 전송 가능
- 전송 채널 선택: TCP 연결 네트워크 채널, 메모리 인메모리 채널, 지역 파일 시스템 채널 중 적절한 것을 선택
- 가까운 위치의 작업 결과를 먼저 취합해 다음 작업에 전달하는 방법
- 데이터를 프리페칭해 워크플로우의 무결절(Seamless) 처리를 향상시켜 처리 시간을 줄임

### 데이터 분할
- 병렬화는 워크플로우 처리 성능에 큰 영향을 주며, 작업 분할과 데이터 분할로 나뉨

## 산업 디지털 전환
### 개념
- 디지털 전환: 기업이 디지털·물리 요소를 통합해 비즈니스 모델을 변화시키고, 산업 전체에 새로운 방향을 정립
- 산업 디지털 전환: 산업 현장에 디지털 전환이 적용되어 새 가치가 창출·전달되는 것
- 산업 데이터: 산업 현장에서 생성되는 데이터. AI·IoT·클라우드·빅데이터·모바일이 디자인·생산·유통·마케팅과 결합해 신제품·신서비스·신산업 표준·신비즈니스 모델을 만듦

### 특징
| 특징 | 사례 | 기술 요소 |
|---|---|---|
| 생산 유연화 | GE가 제트 엔진 노즐 제조 공정에 3D 프린팅을 도입해 조립 공정 단순화·비용 절감 | 3D 프린팅 |
| 제품 지능화 | 테슬라가 자율주행 통합 OS로 차량 성능을 원격 통합·관리 | 자율주행 |
| 서비스 고도화 | 티센크루프가 엘리베이터 고장 수리 데이터로 VR/AR 지원, 유지보수 시간 단축 | VR/AR |
| 신산업·BM 융복합 | 아마존이 물류·구매 패턴 데이터를 분석해 배송하고 고객 경험을 다시 개선에 활용하는 선순환 | 데이터 분석, AI |

### 추진 체계
- 산업디지털전환위원회(위원장: 산업통상자원부장관) 아래 정책협의회
- 선도 과제 선정 → 패키지 지원 → 과제 고도화(스티어링 커미티), 과제 발굴(컨소시엄) → 성공 사례 창출·확산
- 분야별 디지털 연대: 미래차, 가전전자, 헬스케어, 유통, 조선, 소재
- 지능화 협업 지원 센터: 지능화 기술 컨설팅, 협업 인프라 조성, 표준·보안 가이드라인
- 기업 디지털 전환 지원: 업종별 DX 모델 개발·보급, 디지털 전환 기업 인증, 산업 혁신 변화 인재(CA) 양성

### 산업디지털전환촉진법 구성
| 장 | 주요 조문 |
|---|---|
| 제1장 총칙 | 목적, 정의, 국가 등의 책무, 다른 법률과의 관계 |
| 제2장 정책 수립 | 종합계획, 실태조사, 전환위원회와 그 기능 |
| 제3장 산업데이터 활용 생태계 | 활용·보호 원칙, 활용 촉진, 지원 전문회사, 표준화, 품질관리 지원, 데이터 플랫폼 |
| 제4장 선도 사업 지원 | 선정, 지원, 규제 개선 지원·관리·감독 |
| 제5장 기반 조성 | 협업 지원 센터, 기술·서비스 개발 촉진, 전문 인력 양성, 금융·세제 지원, 국제 협력, 우수기업 선정, 안전 확보, 전담기관, 협회 |
| 제6장 보칙 | 재원 조달, 권한 위임·위탁, 벌칙 적용에서 공무원 의제 |

- 신제품 출시·신서비스 제공에 필요한 규제 개선은 규제 샌드박스 제도로 신속 처리

### 산업 데이터 계약 가이드
- 산업 데이터를 잘 활용하면 공정 최적화를 통한 비용 절감, 예방 보수 같은 신서비스, 데이터 자체 판매로 이어짐
- 가이드 구성
  - 개요(총론, 용어 정의)
  - 법적 기초(데이터의 법적 성질, 사용·수익권, 계약 체결 필요성, 보호 방법)
  - 개인정보 처리(이전·활용 관련 법령, 생성-이전-활용 전 주기 처리 방안)
  - 보호·보상(지식재산권 보호, 개인 보상)
  - 계약(계약 유형: 데이터 제공형·창출형·플랫폼형, 표준 계약서)
  - 사례(업종별 사례 분석, 국외 이전 — 미국·베트남·중국·EU 등)

### 성공을 위한 방향
- 정책: 민간이 주도하고 정부는 협업·지원
- 산업: 공급자 중심이 아닌 산업 도메인 맞춤형 전환
- 기업: 개별 기업의 단절된 전환이 아니라 기업 간 협업, 밸류체인으로 데이터가 연결·유통·거래되는 구조

## 정리
- 워크플로우는 "무엇을 어떤 순서로"의 문제이고, 성능은 데이터 이동·분할을 어떻게 줄이느냐에서 갈린다
- 산업 디지털 전환은 그 워크플로우가 산업 현장 데이터에 적용된 사례로, 데이터 계약·표준·보안이 함께 가야 성립한다
