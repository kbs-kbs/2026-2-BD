## 넘파이(NumPy)란
- Numerical Python의 약자
- 파이썬에서 배열을 처리할 때 널리 쓰이는 필수 라이브러리
- 특히 배열 계산에 최적화된 방식과 빠른 처리 속도가 강점
- 특징
  - 처리 속도가 빠름
  - 유연한 연산 제공
  - 배열 내용을 한 번에 디스크에 저장하고 다시 불러오는 기능
  - C/C++로 작성한 코드와 연결 가능
  - 판다스, OpenCV 등 유명 라이브러리가 넘파이 기반

## 배열 생성 함수
| 함수 | 설명 |
|---|---|
| `np.array()` | 파이썬 리스트를 넘파이 배열로 변환, 데이터 형 지정 가능 |
| `np.arange()` | range()와 유사하지만 넘파이 배열용 |
| `np.ones()` | 모두 1로 채운 배열 |
| `np.zeros()` | 모두 0으로 채운 배열 |
| `np.empty()` | 배열을 만들되 초기화하지 않음(쓰레기 값 가능) |
| `np.full()` | 파라미터로 받은 값으로 초기화 |
| `np.identity()` | 대각선 1, 나머지 0인 2차원 배열(단위 행렬) |
| `np.random.randint()` | 지정 범위 정수 중 임의 값 |
| `np.random.rand()` | 0부터 0.9999 범위의 임의 값 |

## 데이터 형식(dtype)
- 파이썬 리스트와 달리 넘파이 배열은 데이터 형식을 지정
- 정수, 실수, 불리언, 복소수, 문자열 등 다양한 형식 지원

| dtype | 설명 |
|---|---|
| int8/16/32/64 | 부호 있는 정수, -128~127 / -32768~32767 / 약 ±21억 / 약 ±900경 |
| uint8/16/32/64 | 부호 없는 정수, 0~255 / 0~65535 / 약 0~42억 / 약 0~1800경 |
| float16/32/64/128 | 부동소수점. float32는 C의 float, float64는 C의 double |
| bool | True 또는 False |
| string_ | 영문 기준 문자열 |
| unicode_ | 한글 등 기준 문자열 |

## 배열의 속성
```python
import numpy as np

ary = np.random.randint(0, 255, size=(2, 3))
ary          # array([[ 57, 210, 207],
             #        [208, 143, 116]])
ary.dtype    # dtype('int32')
ary.ndim     # 2
ary.shape    # (2, 3)
```

| 속성 | 의미 |
|---|---|
| dtype | 데이터 형식 |
| ndim | 차원 수 |
| shape | 각 차원의 크기 |

## 산술 연산과 브로드캐스팅
```python
import numpy as np

ary = np.random.randint(0, 255, size=(2, 3))
ary = ary - 100
ary             # 모든 항목에서 100을 뺀 결과

ary = ary + ary # 자릿수끼리 더함
ary
```

```python
ary1 = np.array([[1, 2], [3, 4]])
ary1 + 10       # array([[11, 12], [13, 14]])
```

- 배열과 숫자는 원래 연산할 수 없지만, 넘파이가 숫자를 같은 크기의 배열로 늘려 연산
- 크기가 다른 배열도 뒤쪽 배열을 앞 배열 크기에 맞춰 확장

```python
ary1 = np.array([[1, 2], [3, 4]])
ary2 = np.array([100, 200])
ary1 + ary2     # array([[101, 202], [103, 204]])
```

```python
ary = np.random.randint(0, 255, size=(2, 3))
ary = 1 / ary   # 나눗셈도 브로드캐스팅
ary = ary ** 5  # 제곱
```

## 첨자와 슬라이싱
```python
import numpy as np

ary = np.arange(10)
ary[0] = 100
ary          # array([100, 1, 2, 3, 4, 5, 6, 7, 8, 9])
ary[2:5]     # array([2, 3, 4])
ary[-1]      # 9
ary[-2]      # 8
ary[:]       # 배열 전체
```

### 뷰(view)와 복사(copy)
```python
ary_sub1 = ary[3:7]      # 부분집합
ary_sub1[:] = 77         # 부분집합 변경
ary                      # 원본도 77로 바뀜 → 메모리 공유
```

```python
ary_sub2 = ary[3:7].copy()  # 완전히 분리된 부분집합
ary_sub2[:] = 88
ary                         # 원본은 그대로
```

- 슬라이싱은 복사가 아니라 **원본과 메모리를 공유하는 뷰**이므로, 독립적으로 쓰려면 `.copy()`가 필요

### reshape
```python
ary1 = np.arange(1, 26, 1)
ary2 = ary1.reshape(5, 5)   # 1차원 → 2차원
ary3 = ary2.reshape(25)     # 2차원 → 1차원
```

- 2차원 리스트 일부를 파이썬 리스트로 추출하려면 반복문이 필요하지만, 넘파이는 `[행, 열]` 슬라이싱으로 한 줄에 끝난다

## 2차원 배열의 슬라이싱
```python
ary = np.arange(1, 17).reshape(4, 4)
```

| 목적 | 코드 | 결과 형태 |
|---|---|---|
| 한 개 행 | `ary[1]`, `ary[1, 0:4]`, `ary[1, :]` | 1차원 `[5, 6, 7, 8]` |
| 인접 여러 행 | `ary[2:]`, `ary[2:4,]`, `ary[2:4, :]` | 2차원 |
| 한 개 열 | `ary[:, 1]`, `ary[0:4, 1]` | 1차원 `[2, 6, 10, 14]` |
| 인접 여러 열 | `ary[:, 2:]`, `ary[0:4, 2:4]` | 2차원 |
| 중간 부분 | `ary[1:3, 1:3]` | 2차원 `[[6, 7], [10, 11]]` |
| 떨어진 행 | `ary[[1, 3], :]` | 2차원 |
| 떨어진 열 | `ary[:, [1, 3]]` | 2차원 |

- 원칙은 `[행, 열]`이며, 행만 쓰면 열은 전체(`:`)로 간주
- `[ , 열]`처럼 행 부분을 비우면 오류

## 배열 연결과 축 전환
```python
ary1 = np.zeros((2, 2), dtype=np.int8)
ary2 = np.ones((2, 2), dtype=np.int8)

np.concatenate((ary1, ary2), axis=0)   # 세로 연결 → (4, 2)
np.concatenate((ary1, ary2), axis=1)   # 가로 연결 → (2, 4)
```

```python
ary = np.array([[1, 2, 3], [4, 5, 6]])
ary.transpose(1, 0)   # 행과 열 교환
ary.T                 # 같은 결과
ary.transpose(0, 1)   # 축이 바뀌지 않아 그대로
```

| 축 | 의미 |
|---|---|
| axis=0 | 행 방향(세로로 붙임) |
| axis=1 | 열 방향(가로로 붙임) |

## 정리
- 넘파이의 핵심은 **같은 형식의 배열**과 **브로드캐스팅**이며, 이 둘이 판다스·OpenCV의 기반이 된다
- 슬라이싱은 뷰(공유)라는 점, 2차원은 `[행, 열]` 순서라는 점이 실수하기 쉬운 부분
