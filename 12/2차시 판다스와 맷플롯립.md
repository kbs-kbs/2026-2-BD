## 데이터프레임과 시리즈
- 넘파이는 동일한 데이터 형식의 배열을 쓰지만, 판다스는 엑셀 워크시트처럼 다양한 형식의 데이터를 배열로 사용
- 그래서 배열(Array) 대신 데이터프레임(DataFrame)이라는 용어를 씀
- 시리즈(Series): 행 또는 열 하나만 추출한 것으로, 인덱스와 데이터로 구성
  - 데이터프레임 = 같은 인덱스를 공유하는 시리즈들을 열 이름으로 나열한 것
  - 시리즈의 값은 내부적으로 넘파이 ndarray

### 핵심 용어
| 용어 | 의미 |
|---|---|
| 데이터프레임(df) | 행과 열로 된 2차원 표 |
| 인덱스(Index) | 각 행의 이름(번호) |
| 컬럼(Columns) | 각 열의 이름 |
| 시리즈(sr) | 한 행 또는 한 열 |

### 접근 방식
| 대상 | 방법 |
|---|---|
| 행 하나 | `df.loc[인덱스이름]` 또는 `df.iloc[행번호]` |
| 열 하나 | `df[열이름]` 또는 `df.열이름` |
| 셀 하나 | `df.loc[인덱스이름, 열이름]` 또는 `df.iloc[행번호, 열번호]` |

- `loc`은 이름으로, `iloc`은 번호로 접근한다는 차이만 기억하면 된다

## 데이터프레임 만들기
```python
import pandas as pd

data = {
    '이름': ['유정', '유나', '민영', '은지'],
    '나이': [30, 28, 31, 29],
    '생일': ['1991.5.2', '1993.4.6', '1990.9.12', '1992.7.19']
}
df1 = pd.DataFrame(data)
df1
```

```python
df2 = pd.DataFrame(data, index=['하나', '둘', '셋', '넷'])
df2
```

```python
df2.index     # Index(['하나', '둘', '셋', '넷'], dtype='object')
df2.columns   # Index(['이름', '나이', '생일'], dtype='object')
```

### 열과 행 추출
```python
sr_name = df2['이름']
type(sr_name)         # <class 'pandas.core.series.Series'>

sr_name.name = '브브걸'
sr_name

sr_two = df2.loc['둘']
type(sr_two)
sr_two
```

```python
df2.loc['넷']['생일']     # '1992.7.19'
df2.loc['넷', '생일']
df2.iloc[3][2]
df2.iloc[3, 2]
```

## 열 추가
```python
# 기본: df[새열이름] = [값1, 값2, ...]
df2['키'] = [163, 165, 168, 166]
```

```python
# 순서가 다르거나 일부만 있는 경우: 시리즈로 지정 (없는 인덱스는 NaN)
sr_vision = pd.Series([1.8, 0.9, 1.2], index=['셋', '하나', '넷'])
df2['시력'] = sr_vision
```

```python
# 중간에 삽입
df2.insert(1, '꽃', ['장미', '백합', '튤립', '데이지'])
```

| 방법 | 코드 | 특징 |
|---|---|---|
| 맨 뒤 열 | `df[열] = [값...]` | 순서대로 매핑 |
| 위치 지정·일부 값 | `df[열] = pd.Series(값, index=...)` | 없는 인덱스는 NaN |
| 중간 삽입 | `df.insert(위치, 열이름, 값)` | 위치 지정 |
| 중간 삽입(시리즈) | `df.insert(위치, 시리즈)` | 순서까지 지정 |
| 맨 뒤 추가 | `df.assign(열이름=[값...])` | 원본 유지 |

## 행 추가
```python
df2.loc['다섯'] = ['재남', '들꽃', 33, '1988.8.8', 177, 1.1]
```

```python
# 딕셔너리로 일부 열만 지정 (생략된 값은 NaN)
df2.loc['여섯'] = {'이름': '보라', '꽃': '민들레', '키': 163, '나이': 34}
```

```python
# 여러 행을 한 번에
new_data = {'이름': ['리사', '제니'], '나이': [23, 22]}
new_df = pd.DataFrame(new_data, index=['블핑', '블핑'])
df2 = pd.concat([df2, new_df])
```

- `pd.concat`은 인덱스가 겹쳐도 그대로 이어 붙이므로, 필요하면 이후에 인덱스를 정리해야 한다

## 열과 행 삭제
```python
df2 = df2.drop(['키'], axis=1)     # 열 삭제
df2 = df2.drop(['셋'], axis=0)     # 행 삭제
df2 = df2.drop(['꽃', '시력'], axis=1)   # 여러 열
df2 = df2.drop(['블핑', '하나'])          # 여러 행(axis 생략)
```

| 대상 | axis |
|---|---|
| 열 | 1 또는 'columns' |
| 행 | 0 또는 생략 |

## 시리즈 연산
- 두 시리즈의 인덱스가 같으면 그냥 연산
- 인덱스가 다르면 인덱스 기준으로 정렬해 맞추고, 한쪽에 없는 인덱스는 결과가 NaN
  - 예: `다현, 정연, 쯔위, 사나`와 `다현, 모모, 사나, 재남`을 더하면 공통인 다현·사나만 값이 나오고 나머지는 NaN

- 막대·선·원·히스토그램·산점도 등 통계 그래프와 지도에 편리


### 스타일 지정
| 매개변수 | 값 | 의미 |
|---|---|---|
| linestyle | '-' | 실선 |
| linestyle | '--' | 대시선 |
| linestyle | ':' | 점선 |
| linestyle | '-.' | 대시점선 |
| marker | 'o', 'x', '+', 's', 'p', 'd' | 원, 엑스, 플러스, 사각형, 오각형, 마름모 |

```python
plt.plot(x_data, y_data, color='green', linestyle=':', marker='o')
plt.show()

plt.plot(x_data, y_data, 'rs')   # 선 없이 빨간 사각형 마커
plt.show()
```

### 여러 개의 선
```python
x_data = ['1st', '2nd', '3rd', '4th', '5th']
y1_data = [90, 28, 75, 58, 78]
y2_data = [80, 80, 50, 40, 90]
y3_data = [40, 50, 90, 90, 60]

plt.plot(x_data, y1_data, 'r-o', x_data, y2_data, 'g:x', x_data, y3_data, 'b--p')
plt.show()
```

- 형식 문자열은 `색+선모양+마커`를 붙여 쓴다(`r-o`, `g:x`, `b--p`)

### 막대·산점도
```python
plt.bar(x_data, y1_data)
plt.show()
```

- 여러 개의 막대를 그릴 때는 x축 데이터를 숫자로 두고 넘파이 배열을 쓰면 코드가 단순해짐
- `plt.bar()`의 `width` 옵션으로 막대 폭을, `plt.xticks()`/`plt.yticks()`로 눈금을 조정

|---|---|

| `df.boxplot()` | 상자 수염 그래프 |

## 정리
- 판다스는 "행 이름(index)과 열 이름(columns)을 가진 표"라고 이해하면 loc/iloc, 열 추가·삭제가 모두 같은 원리로 풀린다
- 시리즈끼리 연산할 때 인덱스가 다르면 NaN이 생긴다는 점이 실무에서 자주 걸리는 부분
- 맷플롯립은 판다스의 `.plot` 계열 뒤에서 실제로 그리는 엔진이며, `autopct` 같은 인수는 맷플롯립 문서에서 찾아야 한다(13주차 참고)
