## 퓨전테이블(Fusion Tables)
- 테이블 데이터를 효과적으로 시각화하도록 도와주는 툴
- 방대한 데이터를 스프레드시트 같은 테이블에 저장하는 온라인 시스템으로, 저장한 정보를 사용자 요구에 맞게 처리하고 결과를 시각화
- 엑셀의 차트와 달리 테이블을 파일이나 이미지 등 **공유 대상으로 지정**할 수 있음
- 구글 맵, 구글 스프레드시트와 간단히 연동되고 엑셀·CSV 파일을 업로드 가능
- 예: 우리나라 문화재 분포를 히트맵으로 표현

## 타블로(Tableau)
- 그래프를 시각화하는 데스크톱 응용 프로그램으로, 온라인 지원과 다양한 콘텐츠 추가가 가능하고 시각적 분석·리포팅 도구를 제공
- 사용이 쉽고 GUI가 직관적
- 피벗 테이블이나 크로스 테이블 작성 도구 중 가장 강력한 기능을 제공
- 데스크톱 인터페이스로 작업하거나, 출판물에 첨부할 다양한 형태의 그래프를 만들 때 적합
- 예: 2005년 허리케인들의 에너지와 바람 세기를 시각화

| 항목 | Fusion Tables | Tableau |
|---|---|---|
| 형태 | 온라인 서비스 | 데스크톱 응용(온라인 지원) |
| 강점 | 공유·구글 맵 연동 | 대화형 분석, 그래프 품질 |
| 데이터 | 엑셀·CSV 업로드 | 다양한 원천 연결 |
| 적합한 경우 | 지도·공유 중심 | 탐색적 분석·리포팅 |

## 팅커팝(TinkerPop)
- 오픈소스 그래프 소프트웨어, 통합된 도구 모음을 만들 수 있으며 구조는 LAMP(Linux, Apache, MySQL, PHP)와 비슷
- REST 기반의 서버 형태로 시스템을 공개
- 전문화된 그래프 데이터베이스에 질의를 작성하고, 상호 연결된 일반 작업을 수행하는 서비스 모음을 제공

| 세부 서비스 | 역할 |
|---|---|
| Blueprints | 그래프 데이터 모델·API |
| Pipes | 데이터 흐름 처리 |
| Gremlin | 그래프 질의 언어 |
| Frames | 프레임 기반 모델링 |
| Furnace | 그래프 알고리즘 |
| Rexster | REST 서버 |

## 클러스터그램(Clustergram)
- 클러스터링과 관련된 표현 소프트웨어
- 계층적 클러스터링을 수행하고 계통도(Dendrogram)나 히트맵 형태로 표현
- 클러스터 개수가 늘어나면 각 데이터 집합 부분에 클러스터를 어떻게 할당하는지 보여 주는 집약 분석 기법
- 예: 클러스터링 결과를 계통도와 함께 히트맵 형태로 표현

## 스페셜 인포메이션 플로우(Spatial Information Flow)
- 특정 정보 안에서 데이터의 흐름을 보여 주는 시각화 기술
- 주로 정보의 흐름을 2차원·3차원 공간에 링 형태로 시각화
- 일반적으로 정보의 흐름이 많을수록 링의 크기가 커짐
- 예: 뉴욕과 세계 각 도시 사이에 흐르는 인터넷 프로토콜 데이터 양 표현

## 정리
- 이 차시 도구는 "무엇을 보여 주는가"로 나뉜다
  - 값의 분포: Fusion Tables, Tableau
  - 구조·관계: TinkerPop, Clustergram
  - 흐름: Spatial Information Flow
- Tableau는 분석 과정을 직접 조작하며 통찰을 얻는 도구, Fusion Tables는 결과를 공유·배포하는 도구라는 성격 차이가 크다
