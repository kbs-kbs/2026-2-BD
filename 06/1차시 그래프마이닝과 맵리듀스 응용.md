## 그래프마이닝 기술
- 페이스북·트위터 같은 소셜 미디어 데이터를 표현하는 방법(그래프)에 마이닝 기술을 적용하는 것
- 일정 빈도 수 이상의 특정 패턴을 모두 찾아내는 방법

### 빈발 부분 그래프 마이닝
- 전체 그래프에서 자주 발생하는 부분 그래프를 발견
- 그래프 데이터베이스에서 모든 빈발 부분 그래프를 찾는 기법
- 성능이 효율적이고 확장성이 뛰어난 gSpan을 널리 사용

두 가지 특징 선택 방법
| 방법 | 내용 |
|---|---|
| 도약 탐색(Leap Search) | 측정 기준을 최소 지지도로 정하고, 최소 지지도를 다양하게 바꿔 가며 gSpan 과정을 반복해 분류 성능이 높은 특징을 선택 |
| 모델 기반 탐색 트리(Model Based Search Tree) | gSpan으로 찾은 빈발 부분 그래프 중 가장 분류 성능이 높은 것의 포함 여부를 측정하며, 그래프 DB가 완전히 분할될 때까지 이분할 반복 |

- 모델 기반 탐색 트리는 같은 부분 그래프를 여러 번 계산하는 중복 연산이 생길 수 있다는 점이 한계

## 기존 알고리즘을 맵리듀스로 바꾸기
### 1. 도형 세기
- 입력 그래프의 각 노드가 몇 개의 도형(삼각형 등)에 속하는지 map으로 세고 reduce로 합산하는 형태로 변형

### 2. 컬럼 빈도수 측정
- 맵 함수와 리듀스 함수의 입력·출력은 모두 키-값 순서쌍으로 정의
- 예: employees.txt에서 FIRST(이름)별 빈도수 측정

```python
def getName(line):
    return line.split('\t')[1]

def addCounts(hist, name):
    hist[name] = hist.get(name, default=0) + 1
    return hist

input = open('employees.txt', 'r')
intermediate = map(getName, input)
result = reduce(addCounts, intermediate, {})
```

```python
# 키-값 쌍을 명시하는 형태
def getName(line):
    return (line.split('\t')[1], 1)

def addCounts(hist, (name, c)):
    hist[name] = hist.get(name, default=0) + c
    return hist

input = open('employees.txt', 'r')
intermediate = map(getName, input)
result = reduce(addCounts, intermediate, {})
```

- 하나의 노드 안에서 반복 결과를 먼저 결합하려고 addCounts를 추가로 정의(컴바이너 역할)
- 흐름: 순서 스캔(Split 0~3) → 맵(John 1 …) → all-to-all 해시 분할(Part 0, Part 2) → 정렬-병합 → 리듀스(John 2 …)

### 3. 소셜네트워크 통계(전입 차수)
- 노드 3개, 방향성 있는 에지 그래프에서 전입 차수를 맵리듀스로 계산
- 원 데이터를 에지로만 표현: `<1,2>, <1,3>, <2,3>, <3,1>`
- 각 맵에서 목적 노드 ID로 그룹핑하면 1은 한 번, 2는 한 번, 3은 두 번
- 결과를 다시 `<1,1>, <2,1>, <3,2>`로 표현하고, 이 값을 키로 그룹핑하면 전입 차수 1이 두 번, 2가 한 번 → 분포를 얻음
- 즉 "에지 목록 → 목적 노드별 빈도"를 두 번 반복하면 차수 분포가 된다

### 4. 네트워크 분석: 군집화 상수(Clustering Coefficient)
- 노드들이 뭉치려는 정도가 얼마나 강한지 측정하는 방법, 사람·컴퓨터의 관계 응집도 평가 척도

```text
cc(v) = v의 이웃끼리 실제로 연결된 에지 수 / v의 이웃 중 가능한 모든 쌍의 수
      = Γ(v) 안의 에지 수 / C(dv, 2)
```

- 분모는 노드 v의 모든 차수(dv)를 2로 조합한 값, 분자는 이웃 집합 Γ(v) 안에서 실제 연결된 에지 수
- 예시
  - 이웃 5개 → 분모 C(5,2) = 10, 이웃끼리 연결된 에지 5개 → cc = 0.5
  - 이웃 5개, 이웃끼리 연결된 에지 1개 → cc = 0.1
- 값이 높을수록 그래프 내 노드 간 관계성이 많고, 사회학에서는 사회적 신뢰도가 높다고 해석

### 빅 그래프에서의 맵리듀스
- 순차 알고리즘은 각 노드의 인접 삼각형 수를 세어 군집화 상수를 구하지만, 그래프가 커지면 속도가 떨어짐

```text
for v in V:
    for v1, w in T(v):
        if (v1, w) in E:
            Triangles[v] += 1
```

- 맵리듀스 2단 구성
  - 맵1: 각 u에 대해 이웃 T(u)를 리듀서로 보냄
  - 리듀스1: `<v1, v2; u>` 형태의 2-경로 생성
  - 맵2: `<v1, v2; u>`와 그래프 에지 `<v1, v2; $>`를 리듀서로 보냄
  - 리듀스2: `$`가 함께 오면 v1, v2가 각각 k/3을 받고 u1…uk가 각각 1/3을 받음
- 결과적으로 데이터가 분할된 상태에서 병행 처리가 가능해진다

## 분산 처리 기반 마이닝
| 단계 | 사용 기술 |
|---|---|
| 데이터 액세스 API | Bigtable, HBase |
| 고수준 API | 소잴(Sawzall), Pig, 드라이애드(Dryad) |
| 분산 파일 시스템 | GFS, HDFS, KFS |
| 실행 프레임워크 | 맵리듀스 |

### Apriori 알고리즘의 맵리듀스화
- Apriori는 데이터마이닝의 대표적 연관규칙 알고리즘
- 맵리듀스는 각 트랜잭션의 모든 부분집합을 만든 뒤 각 부분집합의 개수를 세는 방식으로 문제를 해결
- 흐름: 데이터 분할(Split 0~4) → 맵1~3이 후보 집합에 속한 아이템 개수 계산 → 리듀스가 j-길이 빈번 아이템 집합 도출
- 분산 컴퓨팅인 knowledge 그리드 기반의 Apriori Grid Service 제안: 사용자 이동 예상 경로 예측에 활용(VLR·HLR, KBR, Expert System 연계)

### 분류: MReC4.5
- 기존 결정 트리 분류 알고리즘 C4.5를 맵리듀스 기반으로 개선
- 데이터를 분산해 맵에서 분류기를 만들고, 리듀스에서 합치는 방식
- 단계: 분할 → 맵-분류(C1…Cm) → 리듀스-합치기(C)
- 실험 지표: NN(계산 노드 수), BN(기본 분류기 수), PT(분할 시간), MT(맵 시간), RT(리듀스 시간), TT(총 소요 시간)

### 군집화: K-means의 맵리듀스화
- 맵: 입력 점에서 가장 가까운 중심을 찾아 `<center1, p11>` 같은 키-값으로 출력
- 리듀스: `<center1, [p11, p12]>`를 받아 새 중심 `center1'` 계산
- 모든 군집 내용이 더 이상 바뀌지 않을 때까지 반복
- 서브스페이스 군집화도 맵리듀스로 구현해 여러 머신에 데이터를 분산하고, 각 머신이 맡은 데이터만 계산하며 Apriori 방식으로 낮은 차원의 밀집 영역을 찾아감

## 빅데이터 주요 분석 기술
| 기술 | 최초 개발 | 최초 공개 | 주요 기능 |
|---|---|---|---|
| NLTK | E. Loper | 2001 | 문장 분할, 단어 분할 |
| OpenNLP | 아파치 | 2010 | 비정형 텍스트에서 의미 있는 용어 추출 |
| Boilerpipe | C. Kohlschutter | 2010 | 웹 페이지 불필요 데이터 제거, 필요 정보 추출 |
| WEKA | I. Witten | 1993 | 데이터마이닝·기계학습 알고리즘 포함 분석 프로그램 |
| Mahout | 아파치 | 2009 | 확장 가능한 기계학습 알고리즘 개발 프로젝트 |
| scikit-learn | D. Cournapeau | 2011 | 오픈소스 기계학습 라이브러리 |

- NLTK: 문제 해결에 필요한 빌딩 블록을 제공, 접미사 제거로 중심 단어 추출, 동의어 사전 형태로 데이터 정형화
- OpenNLP: 사람·기관 이름, 장소, 시간 등을 추출하는 모델 포함. Java 기반 자연어 처리 솔루션
- Boilerpipe: HTML에서 실제로 중요한 콘텐츠를 찾는 알고리즘을 적용한 Java 라이브러리. 뉴스·기고 분석에 많이 쓰고 블로그·SNS에도 활용
- WEKA: 무료·Java·오픈소스, 플러그인으로 고유 알고리즘 접목 가능, 명령과 GUI 모두 제공
- Mahout: 하둡 기반 병렬 형식, 협력 필터링·클러스터링·분류. 공통 작업이 많은 알고리즘에 적합
- scikit-learn: 서포트 벡터 머신, 로지스틱 회귀, 군집화 등 고수준 인터페이스 제공. 알고리즘보다 과정에 치중하는 사용 환경에 적합

## 정리
- 그래프 마이닝은 "자주 나오는 모양 찾기(gSpan)"와 "얼마나 뭉쳐 있는가(군집화 상수)"로 요약된다
- 기존 알고리즘을 맵리듀스로 바꾸는 공통 패턴은 **키를 무엇으로 잡을지** 정하는 일이다(이름, 목적 노드, 중심점, 아이템 집합)
