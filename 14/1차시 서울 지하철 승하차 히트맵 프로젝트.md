## 프로젝트 개요
- 목표: 데이터 빈도를 쉽게 확인할 수 있는 그래프 그리기
- 위도·경도가 포함된 명확한 지리 정보 데이터를 사용
- 1차 시각화 후 더 명확한 통찰을 끌어내기 위해 2차 그래프를 그리는 과정 학습
- 최종 결과: 시간대별 지하철 승하차 인원 빈도를 지도에 표시

### 문제 정의
- 상황: 지하철에서 가볍게 식사할 수 있는 음식 사업을 준비하는 우진
- 질문
  - 서울 출·퇴근 시간 유동 인구를 표기한 그래프
  - 가장 유동 인구가 많은 지하철역 3개 파악
  - 투자 유치를 위해 서울시 지도에 유동 인구를 알기 쉽게 표기한 그래프 준비

## 지도 라이브러리 Folium
- 파이썬에서 지도를 사용해 시각화하는 라이브러리
- 공식 저장소(github.com/python-visualization/folium)에서 설치 방법·문서·갤러리 확인, Quickstart 페이지에서 다양한 지도 표현 방식 확인
```bash
conda install -c conda-forge folium
```

```python
import folium

seoul = folium.Map(location=[37.55, 126.98], zoom_start=12)
seoul
```

| 인수 | 의미 |
|---|---|
| location | 지도 중심의 위도·경도 |
| zoom_start | 초기 확대 수준 |

## 데이터 수집
- 서울교통공사가 제공하는 연도별·일별·시간대별·역별 승하차 인원 데이터(서울 열린데이터광장, data.seoul.go.kr/dataList/OA-12921)
- 원천 데이터에는 여러 한계가 있어, 이 프로젝트에서는 한 차례 가공한 캐글 데이터 사용
- 필요한 공공데이터 3종
  1. 서울시 역코드로 지하철역 위치 조회 정보
  2. 서울교통공사 지하철역명 다국어 표기 정보
  3. 서울교통공사 연도별·일별·시간대별·역별 승하차 인원 정보
- 가공본: kaggle.com/datasets/kimjmin/seoul-metro-usage ('seoul metro' 검색 → 첫 번째 결과)

| 파일 | 내용 |
|---|---|
| seoul-metro-2021.logs.csv | 시간대별 승하차 인원 |
| seoul-metro-station-info.csv | 지하철역 정보(위도·경도 포함) |

```python
import pandas as pd

data = pd.read_csv("C:/data/seoul-metro-2021.logs.csv")
station_info = pd.read_csv("C:/data/seoul-metro-station-info.csv")
```

## 데이터 시각화
### 히트맵이란
- 데이터가 많은 지역을 뜨겁게 표현하는 방식
- 데이터가 집중된 영역을 쉽게 식별
- 히트맵 플러그인을 제공하는 Folium을 쓰면 지도에 손쉽게 표현

### 역별 승차·하차 인원
```python
from folium.plugins import HeatMap

seoul_in = folium.Map(location=[37.55, 126.98], zoom_start=12)
HeatMap(data=joined_data[['geo.latitude', 'geo.longitude', 'people_in']]).add_to(seoul_in)
seoul_in
```

```python
seoul_out = folium.Map(location=[37.55, 126.98], zoom_start=12)
HeatMap(data=joined_data[['geo.latitude', 'geo.longitude', 'people_out']]).add_to(seoul_out)
seoul_out
```

- `data` 인수에 위도, 경도, 표기할 데이터가 포함된 데이터프레임을 넘김
- 강남역, 잠실역, 광화문 일대 승차 인원이 집중

### 현재 그래프의 한계
- 승차·하차 히트맵이 거의 차이가 없어 보임
- 이유: 데이터를 가공할 때 **시간 정보를 포함하지 않았고**, 역 코드 중심으로 모두 합쳤기 때문
- 출근·퇴근 시간이 고려되지 않아 사업 아이디어를 증명할 장소를 결정할 수 없음
- → 시간 데이터를 넣어 다시 가공

## 시간을 고려한 재가공
### 필터 조건
- 문자열 timestamp를 시간형 Timestamp로 변경하고 시간 정보를 추출
- 오전 9시 이전 = 출근용, 오후 5시(17시) 이후 = 퇴근용

```python
morning_data = data[pd.to_datetime(data.timestamp).dt.hour < 9]
evening_data = data[pd.to_datetime(data.timestamp).dt.hour > 17]
```

- `pd.to_datetime()`으로 형 변환, `.dt.hour`로 시간만 추출, 대괄호 안 조건식으로 행 선택

### 그룹화와 역 정보 결합
```python
morning_station_sum = morning_data.groupby("station_code").sum()
evening_station_sum = evening_data.groupby("station_code").sum()

morning_joined_data = morning_station_sum.join(station_info)
evening_joined_data = evening_station_sum.join(station_info)
```

### 시간대별 히트맵 4장
```python
# 출근 시간 승차
morning_seoul_in = folium.Map(location=[37.55, 126.98], zoom_start=12)
HeatMap(data=morning_joined_data[['geo.latitude', 'geo.longitude', 'people_in']]).add_to(morning_seoul_in)
morning_seoul_in

# 출근 시간 하차
```

## 분석과 결론
| 구간·지역 | 관찰 | 해석 |
|---|---|---|
| 강남역~삼성역 | 승차는 적고 하차가 상대적으로 많음 | 주거지보다 회사가 많은 곳 |
| 신림역 근방 | 출근 시간 승차 많음, 퇴근 시간 하차 많음 | 주거 지역 |
| 가산디지털단지역 | 출근 시간 하차 많음 | 근무자가 많은 곳 |
| 시청역·을지로입구역·서울역 | 출근 시간 하차 많음 | 주거와 회사가 섞인 지역으로 유추 |
| 강남역 | 퇴근 시간 승차가 가장 많음 | 근무 중 이동 또는 퇴근 후 일을 보고 귀가하는 사람이 많을 것으로 추측 |
| 강북 지역 | 퇴근 시간 승하차 변화가 크지 않음 | 한두 역으로 좁히기 어려움 |

- 최종 결론(문제 해결)
  - 출근 시간에 하차해 직장으로 이동하는 사람이 가장 많은 역: 강북의 시청역·서울역, 강남의 강남역·구로디지털단지역
  - 출근 시간 승차 인원을 노린다면 승차가 가장 많은 신림역
  - 퇴근 시간을 겨냥한다면 강북은 피하는 것이 좋음
  - 퇴근 시간 승차가 가장 많은 역은 강남역, 하차가 가장 많은 역은 신림역

## 정리
- 지도 시각화의 순서: 좌표가 있는 데이터 확보 → 위도·경도·값 3열 구성 → `folium.Map` → `HeatMap(...).add_to()`
- 같은 데이터라도 **무엇을 합쳐 버렸는지**에 따라 통찰이 사라진다. 역별 합계만 보면 승차·하차가 구분되지 않지만, 시간 조건을 넣으면 출퇴근 패턴이 드러난다
