## 프로젝트 개요
- 웹 페이지에서 확인한 데이터를 옮길 때의 문제
  - 옮겨 적다가 오타가 나거나 일부 데이터를 누락할 수 있음
  - 데이터가 많으면 모든 페이지를 열어 옮겨 적는 것이 매우 비효율적
- 웹 스크래핑(Web Scraping): 웹 페이지를 구성하는 실제 소스 코드를 읽으면서 원하는 데이터를 추출하는 기술
- 목표
  - 웹 페이지를 구성하는 기본 기술(HTML, HTTP 등) 이해
  - 웹 스크래핑으로 웹 페이지 데이터를 추출하는 방법 학습

| 용어 | 초점 |
|---|---|
| 웹 스크래핑 | 특정 웹 페이지의 데이터를 추출 |
| 웹 크롤링 | 페이지에 있는 웹 주소를 추출해 스크래핑할 대상 페이지를 찾는 개념 |

### 문제 정의
- 상황: 이직하며 퇴직금을 받은 직장인 지희. 수익이 좋은 곳에 투자하려고 주식 지표에 관심을 가짐
- 문제: 주로 방문하는 시세 사이트가 데이터 다운로드 기능을 제공하지 않고, 눈으로 보며 수작업으로 옮기기에는 시간이 너무 오래 걸림
- 필요한 것: HTML 웹사이트 → 웹 스크래핑 → 데이터

## 웹 스크래핑 가능 여부 확인
- 개발자 도구에서 확보한 URL을 브라우저 주소창에 넣어 결과 확인
- 브라우저에서 보인다고 무조건 스크래핑할 수 있는 것은 아니며, **파이썬 코드에서 쓸 수 있는 주소인지** 확인해야 함

```python
import requests

url = 'https://finance.naver.com/item/sise_day.naver?code=005930&page=2'
page = requests.get(url)
print(page.text)
```

- 결과: 오류 메시지와 함께 원하는 HTML 페이지가 보이지 않음
- 원인: 웹 브라우저에서 요청할 때 설정되는 값을 코드에 넣지 않았기 때문. 네이버 주식 사이트는 브라우저가 아닌 방식의 HTTP 요청을 막아 둠

### 요청 헤더 설정
```python
my_headers = {'user-agent': 'Mozilla/5.0'}
page = requests.get(url, headers=my_headers)
print(page.text)
```

- `user-agent` 값을 넣어 "웹 브라우저에서 보낸 요청"임을 알리면 HTML 페이지 내용을 확인할 수 있음
- 이후 `<Ctrl>+<F>`로 화면에서 보던 날짜(예: 2022.08.16.)를 찾아 실제 데이터가 들어 있는지 확인
- 스크래핑 전에 반드시 소스코드로 데이터를 제대로 가져오는지 확인해야, 코드 실수로 오해하며 시간을 낭비하지 않음

## HTML 테이블 데이터 가져오기
- 브라우저 개발자 도구로 수집 대상이 `<table>` 태그 안에 있음을 확인

```python
import pandas as pd

pages = pd.read_html(page.text)
type(pages)   # list
```

- `read_html()`은 HTML의 테이블을 읽어 **데이터프레임 객체의 리스트**로 반환

```python
len(pages)    # 2

pages[0]      # 실제 시세 데이터
pages[1]      # 테이블 아래 페이지 바
```

- 화면에 보이는 표 외에도 `<table>` 태그가 쓰인 곳이 있을 수 있으므로, 어느 항목이 원하는 데이터인지 반드시 확인
- 시세 페이지는 1개인데 결과가 2개인 이유가 바로 페이지 바 표 때문

## URL 분석과 페이징
### 페이징(Paging)
- 데이터를 여러 페이지로 나눠 출력하도록 설정하는 것
- 너무 많은 데이터를 한 번에 보여 주면 로딩이 길어지고 자원 부족으로 오류가 날 수 있음
- 주식 일별 시세처럼 오래 축적한 데이터는 한 페이지에 제한된 개수만 보여 주는 것이 일반적

### 쿼리 문자열
```text
https://finance.naver.com/item/sise_day.naver?code=005930&page=2
```

| 요소 | 의미 |
|---|---|
| `?` | 쿼리 문자열의 시작 |
| `code=005930` | 선택한 종목(삼성전자) |
| `page=2` | 현재 출력 중인 페이지 |
| `&` | 매개변수 구분 |

- URL에는 정적 주소 외에 동적으로 바꿀 수 있는 정보를 메서드 인수처럼 추가하며, 이를 쿼리 문자열 또는 URL 매개변수라고 부름
- 페이지 번호만 증가시키며 반복하면 여러 페이지 데이터를 축적할 수 있음

## 페이징 데이터 수집
```python
new_url = 'https://finance.naver.com/item/sise_day.naver?code=005930&page='
all_tables = pd.DataFrame()
```

```python
for page_number in range(1, 2):          # 테스트로 1페이지만
    full_url = new_url + str(page_number)
    print(f'{page_number} 번째 페이지 읽어오기({full_url})')

    page = requests.get(full_url, headers=my_headers)

    table = pd.read_html(page.text)[0]   # 테이블 1개 중 첫 항목
    print(f'전체 {len(all_tables.index)} 줄에 {len(table.index)} 줄 추가')

    all_tables = pd.concat([all_tables, table])
```

```text
1 번째 페이지 읽어오기(https://finance.naver.com/item/sise_day.naver?code=005930&page=1)
전체 0 줄에 15 줄 추가
```

- `str(page_number)`: 페이지 번호를 문자열로 바꿔 주소 끝에 붙임
- `pd.concat([기존, 새것])`: 리스트 항목 순서에 유의
- 10페이지로 늘리면 `range(1, 11)`로 바꾸고, 실행하면 15줄씩 누적되어 마지막에 135줄에서 15줄 추가로 끝남

### 결손치 제거
```python
all_tables.dropna(inplace=True)
```

- NaN(Not a Number): `<table>` 안에 행은 있지만 데이터가 없는 경우
- 결손치를 제거하면 7개 정보가 있는 100일치 데이터가 남음

## 데이터 시각화
### 상자 수염 그래프(Box plot)
- 데이터를 다섯 가지 지표로 요약해 표기
  - 최솟값, 제1사분위(하위 25% 지점), 제2사분위(중앙값), 제3사분위(상위 25% 지점), 최댓값
- `boxplot()` 메서드 사용, 일일 시세를 월별로 취합해 표현

### 열 이름 정리
```python
all_tables.rename(columns={
    '날짜': 'date', '종가': 'end_price', '시가': 'start_price',
    '고가': 'highest_price', '저가': 'lowest_price'
}, inplace=True)

all_tables.drop(['전일비', '거래량'], axis=1, inplace=True)
```

- 한글 열 이름은 폰트에 따라 그래프 라벨이 깨지거나 문자 세트 불일치로 문제가 생길 수 있어 영문으로 변경

### 중앙값·월 정보 추가
```python
all_tables['midian_price'] = all_tables['highest_price'] - \
    ((all_tables['highest_price'] - all_tables['lowest_price']) / 2)

all_tables['month'] = all_tables['date'].str[0:7]   # 'YYYY-MM'

all_tables.set_index('date', inplace=True)
all_tables.sort_index(inplace=True)
```

- `str[0:7]`: 문자열 슬라이싱으로 연·월까지 잘라 월 정보 생성
- `set_index`로 날짜를 색인으로, `sort_index()`로 오름차순 정렬 → 왼쪽에서 오른쪽으로 날짜가 증가하는 그래프

### 그래프
```python
all_tables.plot.line()               # 전체 숫자 열
all_tables[:15].plot.line(rot=45)    # 앞 15일만, x축 45도

all_tables.boxplot(column=['midian_price'], by=['month'])
```

- 2022년 6월 시세가 크게 하락해 y축 범위가 넓어지면 그래프 간격이 보이지 않으므로 구간을 잘라 확인
- `boxplot(column=..., by=...)`: `plot()`과 다른 메서드이며, `column`은 그릴 열, `by`는 집계 기준
- 주의: 데이터의 일 단위 중앙값과 상자 수염 그래프에서 보이는 **월 단위 집계 중앙값**은 다른 개념

## 분석 결과
- 고가는 68,000을 넘었고 저가는 56,000 근처까지 하락
- 4월보다 5월의 가격 변동 폭이 좁음
- 6월에 큰 낙폭을 기록하며 중간 상자가 가장 큼 → 6월 중 하락폭이 가장 큼
- 7월에는 가격이 더 떨어졌지만 하락폭은 줄었고, 8월에 소폭 반등
- 4월과 8월은 100일 데이터의 시작과 끝이라 온전한 한 달이 아니므로 왜곡 가능성 있음
- 결론: 급격히 떨어지다 다시 반등하는 모습이므로 좋은 투자 종목일 가능성이 있으나, 100일치만으로 판단하기엔 섣부름
- 이 강의는 주식 구매 시점을 논하는 수업이 아니며 분석 방법의 예시로만 참고

## 정리
- 웹 스크래핑의 성공 조건은 세 가지다: 요청이 통과하는가(user-agent), 원하는 표가 HTML에 있는가(개발자 도구), 여러 페이지를 URL 규칙으로 넘길 수 있는가(쿼리 문자열)
- 수집 후에는 결손치(페이지 바 행의 NaN) 제거가 필수이며, 시각화 전에 열 이름·날짜 색인·집계 기준(월)을 정리해야 한다
