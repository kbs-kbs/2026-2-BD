## 빅데이터의 등장 배경
- 1990 이후 인터넷이 확산되면서 데이터가 무수히 발생
- Fat 클라이언트 (2-Tier C/S) -> Fat 서버 (3-Tier C/S)
- 앱 까보면 DB 비번 털리는데 이게 말이 돼? - 웹 애플리케이션 서버(WAS)'만 DB 비밀번호를 알게.
- 폐쇄망 중심이었기 때문에 웹으로 가기위한 기술적 필연이었음
- 데이터양 증가로 기존의 저장, 관리, 분석 기법으로는 처리에 한계 발생
- 패러다임의 변화:
  - PC 시대(아날로그와 대비되는 디지털이라는 키워드) - 인터넷 시대(오프라인-온라인) - 모바일 시대(유선-무선) - 스마트 시대(도구-비서)

### 데이터 규모
- 1990 100엑사바이트
- 2011 제타바이트 진입
- 2020 제타바이트 본격화

### 데이터 유형
- 정형 데이터
- 비정형 데이터
- 사물정보, 인지정보

### 데이터 특성
- 구조화
- 다양성, 복합성
- 현실성, 실시간성

### 빅테이터가 차세대 이슈로 떠오르는 이유
- 정보화 시대 - 스마트 시대 정보통신기술의 주도권이 데이터로 이동
- 관계형- 비관계형
- 시맨틱 분석으로 나아감



## 빅데이터의 개념과 속성

규모, 다양성, 속도(3V) + 정확성(4V) + 가치(5V)

### 광의의 빅테이터 정의
- 인재/조직
- 데이터 처리/축적/분석 기술
- 데이터(비정형, 정형)
