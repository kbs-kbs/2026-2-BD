## 리얼리티마이닝
- 데이터마이닝 기술의 일종으로, 모바일 기기로 사용자의 인간관계·행동 방식·라이프스타일을 분석
- '현실 마이닝'이라고도 함
- 다른 마이닝 기술과 달리 생체 인식으로 소비자에게 맞춤화된 마케팅을 하거나, 사용자 감정에 따른 심리 변화를 추적해 제품 판매에 반영
- 실제 정보인 빅데이터를 대상으로 하며, 생체 인식을 이용해 사용자의 행동과 상황을 종합적으로 분석할 수 있다는 것이 장점

### 생체 데이터 마이닝 과정
| 구분 | 내용 |
|---|---|
| 마이닝 준비 | 대상 영역 이해, 데이터 이해, 데이터 준비 |
| 데이터 | 맥박·활동량 등을 USB·블루투스로 스마트폰에서 수집, 생체 데이터베이스 서버에 DB 구축 |
| 패턴 발견 | 순서 패턴, 로지스틱 회귀, 신경망, 협회 규칙, 결정 트리 |
| 패턴 분석 | 운동 치료 컨설팅, 위험 분석, 건강 평가, 의학 기반 시스템 구조 |
| 의사 결정 | 만성 질환 예방 관리, 발굴한 지식 활용 |

- 흐름을 한 줄로: 데이터 → 패턴 발견 → 패턴 분석 → 의사 결정

## 군집화 기술
- 주어진 빅데이터에서 데이터들의 특성을 고려해 군집을 정의하고, 군집을 대표할 수 있는 대표점을 찾는 것

### 계층적 군집화
- 각 데이터 점을 하나의 군집으로 두고, 이들 간 거리를 기반으로 분할·합병해 가는 방식
- 데이터 샘플은 분할된 수열로 묶임
- 계통도(Dendrogram)로 각 계층에서 군집들의 유사성을 쉽게 확인
- 두 방향
  - 흡수(Agglomerative): 아래에서 위로 처리하며 n개 군집을 연속적으로 합침
  - 분리(Divisive): 위에서 아래로 분류하며 하나의 군집에 n개 샘플이 있는 상태에서 연속 분리

### 분할적 군집화
- k개의 분할 영역을 정하는 방법으로, 유클리디안 거리 계산에 기반
- K-means: 미리 정한 k개 군집으로 데이터를 분류

K-means 수행 과정
1. 군집 개수 k를 정하고 각 군집에 초기 중심을 하나씩 할당해 위치 설정
2. 각 데이터를 가장 가까운 중심점의 군집에 할당(거리는 유클리디안 거리)
3. 할당된 데이터를 중심으로 각 군집의 새 중심점 계산
4. 새 중심점이 기존과 다르면 2로 돌아가 반복, 같으면 종료

| 구분 | 계층적 군집화 | 분할적 군집화(K-means) |
|---|---|---|
| 방향 | 합병 또는 분리 | 중심점 반복 갱신 |
| k 결정 | 사후에 계통도로 판단 | 사전에 지정 |
| 결과 | 계통도·유사도 구조 | k개 군집과 중심점 |
| 비용 | 데이터가 많으면 계산량 큼 | 반복 횟수에 비례 |

## 소셜네트워크분석
- 인접 행렬과 각 항의 관계를 표현한 네트워크를 다룸
- 노드를 사람·정보로, 간선을 관계로 보는 그래프 분석

### 시멘틱 기술
- 복잡하고 이질적인 그래프 구조를 트리플(주어-서술어-목적어)로 구성된 RDF 그래프로 표현
- 표준 기반이라 의미의 모호성이 없는 정보 표현과 상호 호환성을 확보
- 상호 이질적 정보를 단일 표현 체계로 통합·연계, 그래프 구조와 각 노드의 특성 정보를 함께 표현
- 단일 서버에서 10억 트리플 이상의 대규모 그래프를 표현·저장·관리
- SPARQL로 강력한 질의와 복잡한 데이터 연산 처리
- URL 기반이라 분산 그래프 DB 구현과 분산 질의에 유리
- 동적으로 바뀌는 그래프 정보의 실시간 적용·질의·연산 가능
- 온톨로지 OWL 및 규칙과 결합해 연역적 논리 추론, 기계학습과 연동한 하이브리드 분석 체계 구현
- RDF(S)를 쓰므로 사람의 연결 구조와 정보 연결 구조를 통합 표현하고 필요에 따라 부분 분리·단순화가 쉬움

### 시멘틱 네트워크 기반 분석의 특징
- 거대한 글로벌 네트워크에서 의미적 연관성이 있는 서브 네트워크를 분리하고 수학적 분석 모델을 적용·해석
- 의미 조건으로 서브 네트워크를 추출할 때 SPARQL 사용
- 중심성 지표 예: 연결 중심성(degree centrality), 근접 중심성(closeness centrality)
- 응용 사례: BKNetwork.org의 지식 네트워크 전문가 검색 서비스
  - 부산 출신·부산 지역 활동 학계·산업계·관계·문화예술계 전문가 검색
  - 과정: 대상 콘텐츠 수집(인물 정보, 연구 정보) → 지식인 정보 색인 → 주제어 질의로 관련 지식인 검색 및 주제 관련 지수 산정 → 랭킹

## 지표·기법 비교
| 항목 | 무엇을 보는가 | 결과 |
|---|---|---|
| K-means | 중심점과의 거리 | k개 군집 |
| 계층적 군집화 | 군집 간 거리 | 계통도 |
| 연결 중심성 | 연결된 간선 수 | 영향력 있는 노드 |
| 근접 중심성 | 다른 노드까지의 거리 | 네트워크 중심에 가까운 노드 |
| RDF/SPARQL | 트리플의 의미 관계 | 서브 네트워크 추출 |

## 정리
- 리얼리티마이닝은 "누가 어디서 무엇을 하는가", 군집화는 "비슷한 것끼리 어떻게 묶는가", 소셜네트워크분석은 "누가 어떻게 연결되어 있는가"를 다룬다
- K-means는 k를 먼저 정하고, 계층적 군집화는 결과를 보고 k를 판단한다는 차이가 실무 선택 기준이 된다
