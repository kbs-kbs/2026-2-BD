## 데이터마이닝(Data Mining)의 개념
- 저장된 방대한 데이터 안에서 자동으로 체계적이고 통계적인 규칙·패턴을 찾아내는 데이터베이스 파생 기술
- 다른 말로 KDD(Knowledge-Discovery in Databases), 각종 DB에 내재된 의미 있는 지식의 발견이라는 뜻
- 활용 분야
  - 통계학: 탐색적 데이터 분석, 가설 검증, 다변량 분석, 시계열 분석, 일반 선형 모형
  - 데이터베이스: OLAP(On-Line Analytic Processing, 온라인 분석 처리)
  - 인공지능: SOM(Self-Organizing Map, 자기조직화지도), 신경망, 전문가 시스템
- 대상: 심리 DB, 시계열 DB, 멀티미디어 DB, 소셜 미디어 DB, 경영 DB, 마케팅 DB, 금융 DB, 학사 DB 등
- 결과는 DB 속에 내재된 의미 있는 패턴을 분석해 현실에 적용하는 것

## 데이터마이닝 기법
| 기법 | 내용 | 예 |
|---|---|---|
| 분류(Classification) | 일정 집단에서 특정 정의를 이용해 분류·구분을 추론 | 이탈 고객 분류 |
| 예측(Forecasting) | 데이터 집합의 패턴을 기반으로 미래를 예측 | 수요 예측 |
| 시계열 분석(Time-Series) | 시간 변화에 따라 일정 간격으로 저장한 연속적 통계 수치 분석 | 주가 시계열 분석 |
| 회귀분석(Regression) | 하나 이상 변수 간의 영향·관계를 분석·추정 | 매출과 광고비의 관계 |
| 군집화(Clustering) | 구체적 특성을 공유하는 군집을 찾음. 미리 정의된 특성 정보가 없다는 점에서 분류와 다름 | 비슷한 행동 집단 구분 |
| 연관규칙(Association Rule) | 동시에 발생한 사건 간의 관계 정의 | 장바구니 상품 관계 |
| 요약(Summarization) | 데이터의 일반적 특성·특징의 요점을 간략히 정리 | 리포트 요약 |
| 연속성(Sequencing) | 시간에 따라 순차적으로 나타나는 사건의 종속성 | A 구입 후 B 구입 확률, 계절 매출 변동 |

- 두 갈래로 묶으면 이해가 쉽다
  - 예측·결정(Predictive): 분류, 예측, 회귀분석, 연속성
  - 표현(Descriptive): 군집화, 연관규칙, 시계열 분석, 요약

## 텍스트마이닝
- 비·반정형 텍스트 데이터로 구성된 빅데이터에서 자연어 처리 기술에 기반해 의미 있는 정보를 추출하는 기술
- 분석 대상 비교
  - 데이터마이닝: 관계형 DB, XML 문서 같은 **구조화된** 데이터
  - 텍스트마이닝: 텍스트 문서, 이메일, HTML 파일 같은 **비·반정형** 텍스트

### 4단계 절차
| 단계 | 내용 |
|---|---|
| 정보 수집 | 비·반정형 텍스트 데이터 수집 |
| 정보 처리 | 대용량 데이터에서 특정 키워드나 의미 있는 요소를 추출하려는 전처리 |
| 정보 추출 | 수학적 모델·알고리즘으로 유용한 정보 추출. 가장 중요한 단계 중 하나이며 TF-IDF를 많이 사용 |
| 정보 분석 | 최종 키워드·의미 요소의 우선순위 도출 |

- TF-IDF(Term Frequency-Inverse Document Frequency): 여러 문서로 된 문서군에서 어떤 단어가 특정 문서 안에서 얼마나 중요한지를 나타내는 통계적 수치
- 단어 빈도(TF)가 높고, 다른 문서에서는 흔하지 않을수록(역문서빈도 IDF) 그 문서를 대표하는 단어가 된다

### 자연어 분석 기반 처리 흐름
1. 원시 문장 → 전처리 → 용어 인식 → 경계 인식
2. 품사 부착 → 구문 구조 부착
3. 기본 구 인식 → 개체명 인식
4. 술어-논항 인식 → 관계 추출 → 의미 분류
- 예: "To reduce the rate of macrosomic(질병), glycemic(치료제) should be initiated before 34 weeks." 에서 중요한 단서 단어는 macrosomic을 수식하는 reduce, glycemic을 수식하는 initiated
- 개체명 주변 문맥을 쓰는 두 방식
  - 평면 표현에서 개체명 좌우 단어를 고려: 주변 문맥을 반영하지만 불필요한 단어가 섞임
  - 두 개체명을 포함하는 하위 트리의 중심어를 사용: 핵심 정보를 놓칠 수 있음

### 데이터 분석 방법론
| 단계 | 내용 |
|---|---|
| 전처리(Processing) | 분석에 적당한 포맷으로 데이터 전처리 |
| 분석(Analysis) | 중요한 개념·용어를 텍스트마이닝으로 추출 |
| 개선·이해(Refining & Comprehension) | 추출된 개념·용어의 패턴 분석 |
| 보고·기록(Reporting & Scoring) | 분석 결과 보고 |

## 오피니언마이닝
- 빅데이터에 포함된 어떤 사안·인물·이슈·이벤트에 대한 사람들의 의견이나 평가를 분석하는 것
- 세 단계
  - 특징 추출: 의미 있는 요소·특징 추출
  - 의견 분류: 어떤 의미로 사용되었는지 분석·분류
  - 요약·전달: 선호도가 드러난 오피니언 정보를 요약해 사용자에게 전달

### 긍정·부정 의견 분류 과정
1. 긍정·부정을 표현하는 단어 정보 추출
   - 기존 구축 사전을 쓰거나 수작업으로 도메인 고빈도 단어 확인
   - 학습 데이터의 통계 정보로 자동 추출도 가능
   - 별점이 아주 높은 리뷰의 고빈도 단어 → 긍정, 아주 낮은 리뷰의 고빈도 단어 → 부정
2. 세부 평가 요소와 그것이 가리키는 오피니언의 연결 관계를 포함한 문장 인식
   - 1단계 어휘 정보로 세부 평가 요소와 긍정/부정 표현을 찾고 문장 단위로 분류
   - 대량 레이블 학습 데이터를 만들어 나이브 베이즈, 최대 엔트로피, SVM 같은 알고리즘으로 기계학습
3. 긍정/부정 표현의 수와 유용한 문장을 추출해 리뷰 요약 생성
   - 세부 평가 요소별 긍정·부정 비율 차이로 사용자 선호를 제시할 수 있음

- 예: 맛집 리뷰를 전체·식재료·맛·양·서비스·위생·분위기·주차·가격·대표메뉴로 나눠 긍정 비율을 제시하면, "가격 대비 만족" 같은 판단이 근거를 갖게 된다
- SNS는 사람들의 네트워크 관계와 대화 내용에 오피니언이 포함되고 주제·대상·인물이 국한되지 않아 오피니언마이닝이 많이 활용됨
- 처리 흐름: SNS 고객 의견 수집 → 기업 DB의 이름과 매칭되는 문장 추출 → 세부사항별 의미 극성 판별 → 분석 결과

## 세 기법 비교
| 항목 | 데이터마이닝 | 텍스트마이닝 | 오피니언마이닝 |
|---|---|---|---|
| 대상 | 구조화된 DB | 텍스트·문서 | 의견·평가가 담긴 텍스트 |
| 목적 | 규칙·패턴 발견 | 의미 있는 정보 추출 | 긍정·부정 판별과 요약 |
| 핵심 기법 | 분류·군집·연관규칙 등 | TF-IDF, 자연어 분석 | 어휘 사전, 기계학습, 극성 판별 |
| 결과 형태 | 모델·규칙 | 키워드·개체·관계 | 평가 요소별 선호도 |

## 정리
- 데이터마이닝은 "무엇이 함께 일어나는가", 텍스트마이닝은 "무엇이 중요한 단어인가", 오피니언마이닝은 "좋은가 나쁜가"를 묻는다고 구분하면 된다
- TF-IDF, 개체명 인식, 극성 분류가 세 기법을 잇는 공통 도구다
